Feature cards

Vanilla JavaScript

ES6+ modules decorate server-rendered markup with no build step.

Modern CSS

Grid, Flexbox, and custom properties, scoped per block.

Edge Delivery

Content and code are composed at the edge for a perfect score.

Two columns

The columns block arranges default content into a responsive grid that collapses to a single column on small screens.

Each column is authored as a table cell and decorated into a flex layout by columns.js.
